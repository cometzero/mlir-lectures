# MLIR NPU Lecture 19 Materials

Topic: Runtime / ABI / Codegen

This package contains slides, lecture notes, worksheet, handout, quiz, quick reference, MLIR/C/C++/YAML examples, and diagrams for Lecture 19.

Pseudo IR note: files using `npu_rt` or `npu_kernel` are educational pseudo dialect examples. They are intended to document NPU compiler/runtime contracts, not to compile on upstream MLIR as-is.
