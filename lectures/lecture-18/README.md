# MLIR NPU Lecture 18 Materials

Topic: Custom NPU Dialect - `npu.matmul`, `npu.dma`, `npu.barrier` ODS design.

This package contains slides, lecture notes, worksheet, handout, quiz, quick reference, MLIR/TableGen/C++ skeletons, and diagrams. Files use English names for download reliability.

The `.mlir`, `.td`, and `.cpp` files are educational skeletons. Several examples contain pseudo `npu.*` IR and are not intended to compile with upstream MLIR unless the custom dialect is implemented and registered.
