# MLIR NPU Lecture 17 Materials

Topic: Fusion, Layout Propagation, and Transformer MLP fusion candidate analysis.

Files include slides, lecture notes, worksheet, handout, quiz, quick reference, MLIR examples, pseudo C++ pass skeletons, diagrams, and a simple memory traffic calculator.

Most custom `npu_graph.*` and `npu.*` operations are pseudo IR used for architectural/compiler education. They are intended to express target contracts, not to compile as-is in upstream MLIR.
