# MLIR NPU Lecture 08 Materials

Lecture 08 covers SCF/Affine loops for NPU compiler lowering.

## Files
- `MLIR_NPU_Lecture_08_Slides.pptx` / `.pdf`: lecture slides
- `MLIR_NPU_Lecture_08_Notes.docx` / `.pdf`: instructor notes
- `MLIR_NPU_Lecture_08_Worksheet.docx` / `.pdf`: student worksheet
- `MLIR_NPU_Lecture_08_Handout.md`: quick handout
- `MLIR_NPU_Lecture_08_Quiz.md`: quiz and answer sketch
- `examples/`: MLIR and helper-code examples
- `assets/`: diagrams

## Core exercise
Design an M/N/K tiled matmul loop nest and DMA ordering for NPU execution.
