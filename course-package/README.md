# MLIR NPU Compiler Course Package

Prepared: 2026-05-05

This package contains English-filename downloadable materials for a 20-lecture course on MLIR for AI/NPU compiler development.

## Files

- MLIR_NPU_Compiler_20_Lecture_Notes.pdf
- MLIR_NPU_Compiler_20_Lecture_Slides.pptx
- MLIR_NPU_Compiler_20_Lecture_Slides.pdf
- MLIR_NPU_Compiler_20_Lecture_Course_Plan.md
- MLIR_NPU_Compiler_Quick_Reference.md
- examples/*.mlir and examples/*.md

## Usage

1. Start with Course Plan and Lecture Notes.
2. Use the slide deck for lectures.
3. Inspect examples with your local LLVM/MLIR checkout.
4. Complete the capstone design spec after Lecture 20.

Note: MLIR evolves quickly. Verify exact pass names and command-line options against your LLVM revision.
